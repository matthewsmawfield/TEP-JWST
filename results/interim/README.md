# Interim Results Provenance

This directory stores intermediate sample catalogs generated by upstream pipeline stages and consumed by downstream analyses.

## Core Sample Files

1. `step_001_uncover_full_sample.csv`: UNCOVER DR4 SPS catalog after applying canonical quality cuts (`use_phot == 1`, $4 < z < 10$, $\log M_* > 8$, valid sSFR and mass-weighted age).
2. `step_001_uncover_multi_property_sample.csv`: UNCOVER DR4 multi-property sample (`use_phot == 1`, valid metallicity with uncertainty $< 0.5$, valid dust attenuation).
3. `step_001_uncover_z8_sample.csv`: UNCOVER DR4 $z \ge 8$ sample (`use_phot == 1`, $\log M_* > 8$, valid dust attenuation).
4. `step_002_uncover_full_sample_tep.csv`: Full sample augmented with TEP model calculations ($\Gamma_t$, $R_{\rm ML}$, $\log M_{\rm halo}$, cosmic time, etc.).
5. `step_002_uncover_multi_property_sample_tep.csv`: Multi-property sample augmented with TEP model calculations.

## Downstream Consumption

Downstream pipeline steps load these interim files via `results/interim/` (or fallback paths in `data/interim/` if present). Final step outputs, statistical summaries, and figures are written to `results/outputs/` and `results/figures/`, respectively.
